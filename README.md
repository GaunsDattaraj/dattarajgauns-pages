# Child Websites Suite for www.dattarajgauns.com

A deploy-ready bundle of 5 lightweight, static HTML5 child pages designed to reinforce verified entity signals (Schema.org JSON-LD `Person` + `Organization` + `sameAs` graph, Open Graph metadata, and clean links to `https://dattarajgauns.com/`) for **Dattaraj Pratap Gauns (Founder & CEO, ATLAS CORPORATION)**.

## Included Pages
1. `index.html` — Official Profile Hub & Directory
2. `atlas-corporation.html` — ATLAS CORPORATION (Goa-based Technology E-Commerce Enterprise)
3. `biography.html` — Founder Biography (BITS Pilani M.Tech, Former IBM Professional, CEO)
4. `technology-ai.html` — Artificial Intelligence, Machine Learning & Software Engineering
5. `goa-vision.html` — Goa Roots, National Ambition & Direct Contact
6. `sitemap.xml` — XML sitemap template (update the base URL to match your GitHub Pages repo or subdomain)

## Quick Deploy on GitHub Pages (Free)
1. Create a public GitHub repository under your account (`GaunsDattaraj`), for example `profile` or `dattaraj-gauns`.
2. Upload all HTML files and `sitemap.xml` to the repository root.
3. In GitHub, open **Settings -> Pages**, choose **Deploy from a branch** (`main` / `root`), and click **Save**.
4. Update the `<loc>` URLs in `sitemap.xml` to your live GitHub Pages URL (e.g. `https://gaunsdattaraj.github.io/profile/`), then submit the sitemap in Google Search Console.
